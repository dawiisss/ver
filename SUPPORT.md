# Support

## Getting Help with VER

Thank you for using **VER (Very Easy Remote)**! Here are the best ways to get help and support:

---

### 📖 Documentation

* [README.md](README.md): Quick start, dependency setup, feature breakdown, and keyboard shortcuts.
* [CHANGELOG.md](CHANGELOG.md): Complete record of version changes and new features.

---

### 💬 Community & Discussions

* **Questions & Discussions**: Use [GitHub Discussions](https://github.com/dawiisss/ver/discussions) to ask questions, share setups, or discuss ideas.
* **Feature Requests**: Open a [Feature Request](https://github.com/dawiisss/ver/issues/new?template=feature_request.yml) on GitHub.

---

### 🐛 Bug Reports

If you've encountered a bug or unexpected behavior:
1. Check if the issue has already been reported in [GitHub Issues](https://github.com/dawiisss/ver/issues).
2. If not, please file a new [Bug Report](https://github.com/dawiisss/ver/issues/new?template=bug_report.yml).
